Lab 9: Add a README

Lab 9 of 20

Goal

Practise adding another file to an existing repository.

In the support-tools folder, create a new file named README.md.

Make sure the file is named README.md, not README.md.txt.

Add:

# Support Tools

Practice repository for CIS-1160 Git activities.

This repository contains simple technical support documentation used to practise version control.

Save it.

Check:

git status

Stage and commit:

git add README.md
git commit -m "Add project README"

Instructions

Follow the steps in order and check the repository state as you work.

Commands

Use these commands as you work through the instructions. Run them in Git Bash.

git status
git add README.md
git commit -m "Add project README"

What to Notice

The README is a second tracked file after it is committed.

Check Your Work

Run git status and confirm a clean working tree after the README commit.
